How to whitelist Sitebulb on Cloudflare. Login to your Cloudflare account and select the website in question. From the left hand menu, open the Security dropdown and then select WAF (Web Application Firewall). To create a new rule, press the button for Create rule on the 'Custom rules' tab: Give your firewall rule a name – you now have 2 options for unblocking Sitebulb. If you have a static IP address, we advise you to select IP Source Address and enter in your own external IP . If you want to crawl with Sitebulb from different locations/IP addresses or might not have a static IP address you can add Sitebulb to your allowed User Agent strings. The IP address of your Sitebulb Cloud server is constant over time, so whitelisting it will be a good long-term solution, that you can share with your clients. You can find your IP address within Sitebulb, by following the steps outlined in this document .
