How to share an Audit. Got an audit you’re proud of, or a project that you need to share? Sitebulb offers a Share Audit function that allows you to create a .sbp file that can be imported by a different Sitebulb user/machine. Navigate to your Audit overview page Find an audit and go to its overview page – you will see the green Share Audit button in the Audit Details card. Build the Audit export Click the Share Audit button. Sitebulb will start the process of generating a sharable export file. Save the Audit export Once the export build is finished click Save to download a copy of the export to your machine. This will save it as a “.sbp” file, which can be imported by another Sitebulb user.
