Edit Scheduled Project Settings and Schedule. Let's say you have a recurring audit set up to run every week, and you have recently implemented Structured Data on your pages. You may now wish to include Structured Data validation as part of your weekly audit in Sitebulb. By editing the project settings, you can go in and add the Structured Data report to your audit, so that Sitebulb will also check this every month. Navigate to Project Settings Navigate to your Project board, and hit the blue button Edit Settings and Schedule : This will open up the familiar 'Audit setup' page, which you can then adjust as required. Change Project settings In this case, all we wanted to do was add Structured Data validation, so it is just a case of checking the 'Structured Data' tickbox and then hitting the Save Changes button. However, you can go in and change any element of the audit setup, including Advanced Settings on the left. Just make sure to hit save! Edit Project schedule At this point you can choose to edit the scheduling of an audit as well. Simply scroll down to the Scheduling tab and make the necessary changes. You can change any element of the schedule, including the recurrence interval and when the next audit should run. Save Changes Make sure to hit the Save Changes button! Every upcoming audit will now run with these settings.
