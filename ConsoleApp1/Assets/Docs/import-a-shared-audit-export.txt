Import a shared Audit export. So you’ve been entrusted with a Sitebulb export, but not sure how to access all that gooey data goodness? Navigate to the Imported tab On the Imported tab click the blue Select file button. This will open a explorer/finder window. Find and select your file Find your .sbp file in your computer and click 'Open'. Start the Import Once you have selected your file, click the green Start Import button. The import window will load up and show your progress; once it finishes you will be able to view your newly imported audit.
