Email Notification Settings. There are some instances where you will want to leave Sitebulb to crawl a website as you get on with other tasks; If you are crawling a larger site that you know will take a few hours If you have scheduled or recurring audits running in the background If you have set up Sitebulb to crawl on a remote machine In all of these cases, it is easy to forget that you sent Sitebulb off to do this task, and so adding an email alert when the crawl is finished can be a helpful reminder. You can set this up in Sitebulb via the 'Crawler Settings' options on the left-hand menu in the audit setup: To set this up, toggle the checkbox on, enter your email address in this box (or multiple addresses, comma separated) and Sitebulb will send you a friendly email whenever your audit is finished: One thing to note is that this needs to be switched on for each audit/project, it does not happen on every single audit by default.
