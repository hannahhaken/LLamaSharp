Language Patterns. Some websites serve different content to users in different regions, based on the accept-language header used in the header request. So a French visitor who tries to go to the /de/ URL might be redirected to the /fr/ version. Since this can affect the ability of a website crawler to perform a complete site crawl, Sitebulb allows you to set up URL patterns to correspond with different language options. Access the Language section via the 'Crawler Settings' options on the left-hand menu in the audit setup, then scroll down to find the language setup area. To add new language patterns, hit the green button Add New Language , which will bring up an overlay for you to enter the pattern.
