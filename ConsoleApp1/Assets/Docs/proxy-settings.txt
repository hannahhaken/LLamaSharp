Proxy Settings. Occasionally, you may want or need to crawl a website through a proxy. This means that Sitebulb would route all its requests through the proxy, when interrogating the website. Proxies aren't generally required or recommended, but are necessary if you need to crawl from a specific location. Please bear in mind that a proxy adds an additional HTTP layer, which will slow down the crawl and can return inaccurate results.
