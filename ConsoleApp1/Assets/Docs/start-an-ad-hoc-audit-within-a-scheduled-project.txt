Start an ad hoc audit within a Scheduled Project. Let's say you have a recurring audit set up to run every month, but your client calls and tells you they have just made multiple changes to the robots.txt file on a whim (b@5$ards!), so you figure 'I'd better audit the site now!'. Well, you can do this too, and setup Sitebulb to run an ad hoc audit, without interfering with your pre-scheduled recurring monthly audit . Navigate to the Project page Navigate to the project page, where you will see details about your next scheduled audit. Start a new audit with current configuration Hit the green button Start a New Audit , and choose 'Start with current configuration' to run a crawl with the exact same settings as your recurring audits. This will allow you to start a new audit right away, and will not change the recurring or scheduled date you have already put in place.
