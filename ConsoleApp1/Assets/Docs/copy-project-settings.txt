Copy Project Settings. Sitebulb allow you to copy settings for an existing project, making new Projet setup a breeze if you are looking to duplicate previous settings. Set up a new Project To copy project settings, you will need to set up a brand new project. Select what Project settings to copy In the first screen you see after creating a new project, you'll find the 'Copy From' drop down box. From here you can select what project you want to copy the settings from. ​ The Copy From feature will copy all the settings precisely from an existing project - even if you're auditing a different website - so it is worth double checking the setup is correct before actually starting the audit, as some settings don't carry across well (e.g. sitemaps, URL Lists, Google Analytics). You can only use the copy project settings feature on new projects you can't copy settings across to existing projects.
