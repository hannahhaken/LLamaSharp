URL received no desktop organic search traffic This means that the URL in question received no organic search traffic from desktop devices, per the connected Google Search Console account. Why is this important? This should be considered a flag - why did the page receive no visits on desktop devices? It could signal an issue with search performance for the page on desktop devices. Please note that this Hint is independent of 2 other Hints: URL received no mobile organic search traffic URL received no tablet organic search traffic So it might be the case that one or both of these Hints were also triggered. What does the Hint check? This Hint will trigger for any internal URL which recorded zero desktop clicks from organic search. This data was collected from Google Search Console, via API, for the connected Property, and for the specified date range. Why is this Hint marked 'Potential Issue'? This Hint is a 'Potential Issue', which means that it is unlikely to be affecting the site at the moment, but should be investigated as it could cause issues in the future. For example, the site you are auditing may be a dedicated mobile site, where you would actually expect to see no desktop traffic. If this is the case, you would simply ignore this Hint. Similarly, it might simply be the case that this is a low traffic page, and there didn't happen to be any desktop visits during the given time frame. However, this Hint will also help you pick out instances where the desktop version of the page is underperforming, which may actually be indicative of a much wider issue.
