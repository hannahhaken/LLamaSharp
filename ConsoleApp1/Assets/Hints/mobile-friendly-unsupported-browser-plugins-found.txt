Unsupported browser plugins found This means that the URL in question utilizes unsupported browser plugins. Why is this important? Plugins are not widely supported by mobile devices (and by default most desktop browsers restrict them), which makes the content unavailable on mobile devices. What does the Hint check? This Hint would trigger for any URL that contains any of the following plugins: Flash Shockwave Java applets Director Silverlight Examples that trigger this Hint: Consider the example below, of a page that utilises a Flash (.swf) plugin - this page would trigger the Hint. How do you resolve this issue? Mobile and desktop browsers are increasingly blocking content from unsupported plugins, so the only real long-term solution is to remove the content and/or replace it with more modern, supported plugins (e.g. HTML5 video players instead of Flash).
