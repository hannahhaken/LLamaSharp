URL received search traffic but 0 goal conversions This means that the URL in question received some organic search traffic, but no goal conversions, per the connected Google Analytics and Google Search Console accounts. Why is this important? If a page has received organic search traffic but no goal conversions, it may mean that the page is poorly set up from a conversion perspective. However, given that it may be perfectly normal for the majority of pages on a site to achieve no goal conversions, please be aware that this Hint is only a Potential Issue. What does the Hint check? This Hint will trigger for any internal URL which recorded some clicks in Search Analytics, and/or some visits in Google Analytics, yet registered no goal conversions in Google Analytics. This data was collected from Google Search Console and Google Analytics, via API, for the connected Property/View, and for the specified date range. Why is this Hint marked 'Potential Issue'? This Hint is a 'Potential Issue', which means that it is not necessarily an issue that is affecting the site at the moment, but should be investigated as it could uncover a deeper problem. There are numerous reasons why a page may not register any goal conversions, the main ones being: The Google Analytics account has no goal conversions configured. It is not a conversion oriented page. So this Hint is only really useful if you are working with a site that DOES have goal conversions set up in Google Analytics, and is heavily conversion focused (e.g. an ecommerce site). In those cases, if this Hint flags for lots of URLs, it may indicate that the site is bloated with lots of pages that don't push the needle in terms of conversion, which may need reviewing.
