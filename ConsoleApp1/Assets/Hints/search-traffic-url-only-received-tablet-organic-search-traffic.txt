URL only received tablet organic search traffic This means that the URL in question only received organic search traffic from tablet devices, per the connected Google Search Console account. Why is this important? This should be considered a flag - why did the page receive visits on tablet devices, but not desktop or mobile devices? It could signal an issue with search performance for the page on desktop and mobile devices. What does the Hint check? This Hint will trigger for any internal URL which recorded some tablet clicks from organic search (i.e. > 0), but no desktop or mobile clicks. This data was collected from Google Search Console, via API, for the connected Property, and for the specified date range. Why is this Hint marked 'Potential Issue'? This Hint is a 'Potential Issue', which means that it is unlikely to be affecting the site at the moment, but should be investigated as it could cause issues in the future. It might simply be the case that there were only a few visits registered during the given time frame, and they just happen to all be on tablet. If this is the case, you would simply ignore this Hint. However, this Hint will also help you pick out instances where the desktop or mobile versions of the page are underperforming, which may actually be indicative of a much wider issue.
